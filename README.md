# 🚀 HTML Sign Up Form ✨

I’m excited to share my **first Sign Up Form built entirely with HTML!** 🖥️  
This form is fully functional and designed to collect user information in a **clean, organized, and user-friendly way**.

I’m currently learning **CSS 🎨**, so this is a **pure HTML version**. A fully polished & styled version will be uploaded soon.

---

## 🔹 Features

- 👤 **Personal Information** – Name, Email, Phone & Gender  
- 🔑 **Account Details** – Username, Password & Confirm Password  
- 🌍 **Preferences** – Student/Teacher selection, Country & Language choices  
- 📝 **Additional Information** – About Yourself  

---

## ✅ Highlights

- ✨ **Clean & semantic HTML structure**  
- 🛠️ **Multiple input types** with required validation  
- 📑 **Organized sections & tables** for clarity  
- 👌 **User-friendly placeholders & datalists**  
- 💻 Fully functional **without CSS or JavaScript**
